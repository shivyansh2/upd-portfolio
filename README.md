# Shivyansh Thakur Portfolio

## Key Features

- Responsive editorial-style landing page
- Featured Figma food-delivery application case study
- Project and education content powered by type-safe Markdown collections
- Dedicated projects, resume, and contact pages
- Downloadable PDF resume
- Netlify Forms contact flow with loading, success, error, and spam-protection states
- Accessible focus styles and reduced-motion support

## Technology

- TanStack Start and TanStack Router
- React 19 and TypeScript
- Tailwind CSS 4 with a custom global design system
- Content Collections with Zod validation
- Netlify Forms and Netlify deployment tooling
- Lucide React icons
